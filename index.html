Flash Games

Classic Flash games, playable again

SWF games and animations on web pages play right in the browser, powered by the open-source Ruffle player. Large web games get a 64-bit native player, so they no longer stop when the page runs out of memory. Try Juicy Breakout on our demo page.

  • SWF games and animations in web pages, on Mac too
  • Virtual gamepad, keyboard and game controller input
  • Game speed from 0.1× to 50×; dialogs stay inside the screen
Game Translation

Play web games in your language

Turn on translation and the quests, dialogue, menus and tips inside Flash web games appear in your language as you play, while the graphics and controls stay the same. Web pages can be translated too.

Installation FAQ

Which devices are supported?

Mac with macOS 12 Monterey or later (Apple silicon and Intel), PCs with Windows 10 or 11, compatible iPhone and iPad devices through the App Store, and Android 7.0 or later. Features and layout may vary by platform.

How do I install on a Mac?

Open the downloaded DMG, drag Zixia Browser to Applications, then open it from Applications or Launchpad. The app is notarized by Apple; if macOS still asks, choose Open. Details on the download page.

Why does Android show an installation warning?

The APK is downloaded directly from this website rather than an app store. Temporarily allow your browser to install unknown apps in Android settings; you can turn that permission off after installation.
