Install on Mac

Three steps on your Mac

  1. 1

    Open the downloaded zixia-browser-mac.dmg. A window with the Zixia Browser icon and an Applications folder appears.

  2. 2

    Drag 紫霞浏览器 (Zixia Browser) onto Applications, then eject the disk image.

  3. 3

    Open Zixia Browser from Applications or Launchpad. The app is signed with a Developer ID and notarized by Apple, so it opens without extra steps. If macOS still asks, choose Open in the dialog.

Works on Macs with Apple silicon (M1 and later) and Intel processors. Flash games and the retro game emulator run natively on both.

Install on Android

Help

Questions

Which Mac models are supported?

Any Mac running macOS 12 Monterey or later, with an Apple silicon (M1, M2, M3, M4…) or Intel processor. The app is a universal binary, so it runs natively on both.

macOS says the app cannot be opened.

The app is notarized, so this normally does not happen. If it does, control-click the app in Applications and choose Open, or allow it under System Settings → Privacy & Security. Make sure you copied the app out of the disk image first.

Windows shows a warning when I run the installer.

The installer is not code-signed yet, so Microsoft Defender SmartScreen or your browser may warn about it. Check the SHA-256 against the value on this page, then choose More info → Run anyway. Security software may also ask you to trust the file.

Why does Android show an installation warning?

The APK is downloaded directly from this website rather than an app store. Temporarily allow your browser to install unknown apps in system settings, then turn the permission off after installing.
