Juicy Breakout

The classic paddle-and-ball game from the talk “Juice it or lose it”. Move the paddle with the mouse or by dragging a finger across the game. The game starts with all the effects on (screen shake, particles, sound, animation); turn them off to see how plain the same game feels without them.
