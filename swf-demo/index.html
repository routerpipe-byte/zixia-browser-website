Zixia Browser

SWF demos

Older web pages often contain SWF ("Flash") content. Zixia Browser plays it with the open-source Ruffle player. Each page below contains one SWF that loads and plays by itself; no account or download is needed.

In Zixia Browser, the ≡ menu has a “Native Flash” switch. Off (default): SWF content plays inside the web page. On: the same content plays in the browser's built-in Ruffle player. Both modes play these demos.

Vector animationRotating rings of shapes, gradients and thin lines, with a live frame-rate readout: a check for smooth playback and crisp edges.Tap, double-tap and keysTap a circle (+1), double-tap the spinning star (+5), and steer the ship to the coin (+2) with the arrow keys or the on-screen controller (≡ → Virtual Controller).SoundSix pads, each playing a short tone generated for this demo. Tap a pad to hear it.

SWF ("Flash") content on these pages is played by Ruffle, an open-source SWF player (MIT / Apache-2.0). It is not Adobe Flash Player. The demos were made for Zixia Browser.
