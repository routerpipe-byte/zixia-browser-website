紫霞浏览器

模拟器演示

紫霞浏览器可以打开你自己下载或导入的 FC（NES）、Game Boy、Game Boy Color 和 Game Boy Advance 游戏文件。应用内不含任何游戏。下面的游戏是可以自由分享的开源自制游戏。

Tobu Tobu Girl Deluxe

Tangram Games 制作的 Game Boy Color 街机风平台游戏：帮 Tobu 一路踩着敌人往上跳，爬到塔顶。

下载游戏（256 KB）

怎么玩

  1. 点“下载游戏”，确认下载。
  2. 在下载列表里打开下载好的文件，游戏会在内置模拟器中启动。
  3. 按 3 次 Start（跳过标志、标题画面和选关）就进入第一关。可用屏幕手柄、游戏手柄或键盘操作。
