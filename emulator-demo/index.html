Zixia Browser

Emulator demo

Zixia Browser can open NES, Game Boy, Game Boy Color and Game Boy Advance game files that you download or import yourself. The app includes no games. The game below is free, open-source homebrew that may be shared.

2048 for NES

The sliding-number puzzle 2048 on the NES: slide the tiles with the D-pad, merge equal numbers and reach 2048. Select turns the music on or off.

Download game (24 KB)

How to play

  1. Tap “Download game” and confirm the download.
  2. Open the finished download in the Downloads list. The game starts in the built-in emulator.
  3. Play with the on-screen controller (D-pad, A, B, Start, Select), a game controller or a keyboard.

2048 for NES by Maciej Muszkowski (source), built with Shiru’s neslib and FamiTone2; released into the public domain under the Unlicense (license text). The game file is the unmodified build from that repository. Based on the game 2048 by Gabriele Cirulli. Zixia Browser uses the open-source emulator cores binjnes (MIT) and mGBA (MPL-2.0).
