Zixia Browser

Emulator demo

Zixia Browser can open NES, Game Boy, Game Boy Color and Game Boy Advance game files that you download or import yourself. The app includes no games. The game below is free, open-source homebrew that may be shared.

Tobu Tobu Girl Deluxe

An arcade platformer for Game Boy Color by Tangram Games: help Tobu climb as high as she can, bouncing off enemies on the way up to the top of the tower.

Download game (256 KB)

How to play

  1. Tap “Download game” and confirm the download.
  2. Open the finished download in the Downloads list. The game starts in the built-in emulator.
  3. Press Start three times (logos, title screen, level select) and the first level begins. Play with the on-screen controller, a game controller or a keyboard.
